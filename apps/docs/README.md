# Gala documentation

The Gala documentation site is a Next.js and Fumadocs application.

## Development

Install Nub 0.8.3, then install dependencies and start the development server:

    nub install
    nub run dev

The site is available at localhost:3000.

## Validation

    nub run test
    nub run format:check
    nub run lint:check
    nub run build

Documentation pages live in content/docs.
