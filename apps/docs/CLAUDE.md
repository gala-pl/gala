# Gala documentation repository

Use Nub 0.8.3 for dependency management, scripts, and TypeScript execution. The application is a root-level Next.js and Fumadocs site.

Run nub install, nub run dev, nub run build, and nub run test for the standard workflow. Keep documentation in content/docs and site identity in lib/site.ts.

All tests must be TypeScript. Add focused coverage for behavior changes, avoid production or test logging, and preserve the docs-only scope of this repository.
