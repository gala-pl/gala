The roadmap is outcome-based. It is a plan, not a list of shipped features.

## Current foundation

The repository has the workspace and a growing frontend path: lexing, parsing, AST/HIR, type and
effect helpers, linearity checks, uncomputation analysis, GIR data structures, diagnostics,
formatting, and source fixtures.

## Next compiler milestones

1. Make frontend diagnostics precise and complete across modules and control-flow paths.
2. Turn GIR into an executable, validated contract with useful dumps and invariants.
3. Implement a small state-vector simulator and wire `gala run` to it.
4. Implement actual QIR lowering and capability validation.
5. Add real gradient lowering, optimization, and classical code generation.

## Language questions still open

- Should in-place gate sugar be the default, or should explicit threading remain canonical?
- Should `Measured<T>` require explicit sampling/value extraction?
- What is the surface syntax for controlled and adjoint functions?
- Should the qubit discipline be strictly linear or affine with compiler-synthesized cleanup?
- How far should `Qubits<N>` sizing go toward dependent typing?

Each language decision should land with a design note, conformance fixtures, and updated examples.
See the repository’s `docs/ROADMAP.md` and `docs/AGENTIC_BUILD_PLAN.md` for the detailed work
package plan.
