## Prerequisites

- Rust with the version selected by [`rust-toolchain.toml`](https://github.com/gala-pl/gala/blob/main/rust-toolchain.toml).
- A working C toolchain for dependencies that require native compilation.
- Git, if you are contributing from a clone.

The repository is a Rust 2021 Cargo workspace. The source of truth for the workspace members and
dependencies is the root `Cargo.toml`; the documentation site is a separate Next.js application
under `apps/docs`.

## Build the compiler

From the repository root:

```bash
cargo build --workspace
```

Run the full Rust test suite:

```bash
cargo test --workspace
```

The normal quality gates are:

```bash
cargo fmt --check
cargo clippy --workspace -- -D warnings
```

## Run the CLI

The CLI binary is the `gala` target in `crates/gala-cli`:

```bash
cargo run --bin gala -- --help
cargo run --bin gala -- build examples/hello_world.gala
```

The first command prints the command surface. The second sends the file through the compiler
driver and prints the current build representation.

## Work on the docs site

The documentation app uses Nub 0.8.3 and Node.js 24+:

```bash
cd apps/docs
nub install
nub run dev
```

Validation commands are `nub run test`, `nub run format:check`, `nub run lint:check`, and
`nub run build`. Content belongs in `apps/docs/content/docs`; keep site identity in
`apps/docs/lib/site.ts`.
