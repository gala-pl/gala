Gala is designed as a classical language with quantum resources. Its syntax uses familiar
functions, bindings, blocks, operators, and pattern forms; the quantum-specific guarantees come
from the type and effect system.

## The three questions to ask

When reading a Gala function, ask:

1. **What values does it consume and return?** `Qubit` and `Qubits<N>` are linear resources.
2. **What can it do?** The effect is `pure`, `quantum`, or `prob`.
3. **Can the compiler reverse it?** Measurement-free quantum code is the candidate for adjoints,
   controlled forms, and automatic uncomputation.
