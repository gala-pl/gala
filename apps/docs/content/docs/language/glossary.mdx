---
title: Language glossary
description: Terms used in Gala’s quantum, type-system, and compiler documentation.
---

| Term | Meaning |
| --- | --- |
| **Linear** | A value discipline in which a resource must be consumed according to ownership rules. |
| **Qubit** | A single quantum resource; it is not an ordinary copyable value. |
| **Ancilla** | Temporary quantum workspace that must be returned cleanly before release. |
| **Effect** | A type-level description of whether code is pure, quantum, or probabilistic. |
| **Measured** | A classical value produced by crossing the measurement boundary. |
| **Liftable** | A value whose provenance can be reversed safely for uncomputation. |
| **Adjoint** | The inverse of a unitary operation. |
| **GIR** | Gala IR, the typed intermediate representation between frontend checks and backends. |
| **QIR** | Quantum Intermediate Representation, an LLVM-based target format intended for hardware. |
| **Salsa** | The incremental query framework used by the driver database. |
| **Conformance fixture** | A source file that pins an expected parser, type, diagnostic, or lowering behavior. |

For the broader quantum and compiler vocabulary, see the repository’s `docs/GLOSSARY.md` and the
[architecture](/docs/architecture) section.
