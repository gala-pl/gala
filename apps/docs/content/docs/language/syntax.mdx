## Lexical structure

Identifiers start with an ASCII letter or underscore. Greek letters in the range used for common
parameters, such as `θ`, are accepted by the lexer. Gala has line comments (`//`) and nested block
comments (`/* ... */`). Strings use double quotes with escapes for newline, tab, quote, and slash.

The lexer recognizes integer and floating-point literals, a complex-literal form, booleans, and
the unit value. It also tracks a source span for every token.

## Keywords

The current token set includes:

```text
fn let mut if else match for in while return import as
struct enum trait impl type const
pure quantum prob
qubit qubits measure reverse adjoint control grad drop
```

Built-in type keywords include `Bool`, `Int`, `Float`, `Complex`, `String`, `Unit`, `Params`,
`Measured`, `Qubit`, `Qubits`, and `Vec`.

## Function declarations

```gala
fn add(left: Int, right: Int) -> Int pure {
    return left + right;
}
```

The parser supports generic parameters, typed parameters, an optional return type, an optional
effect annotation, and a block body. A function body may contain `let`, `return`, expression
statements, and a trailing expression.

## Expressions

The AST models:

- literals and identifiers;
- calls and method calls;
- unary and binary operators;
- blocks, `if`, `match`, `for`, and `while` forms;
- tuples, arrays, lambdas, field access, and indexing.

Operator precedence is encoded in the parser. Ranges use `..`; comparisons include `==`, `!=`,
`<`, `<=`, `>`, and `>=`; boolean operators are `&&` and `||`.

## Types and paths

```gala
Qubit
Qubits<4>
Measured<Bool>
(Int, Float)
[Bool; 8]
fn(Int, Int) -> Int
gala.core.Qubit
```

The grammar and AST have room for structs, enums, traits, implementations, aliases, constants,
and imports. Support should be treated as incremental until it is covered by conformance tests.
