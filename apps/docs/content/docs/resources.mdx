## Useful entry points

- `crates/gala-driver/src/lib.rs`: batch compilation orchestration.
- `crates/gala-driver/src/db.rs`: incremental Salsa queries.
- `crates/gala-types/src/lib.rs`: type, effect, and linearity logic.
- `crates/gala-uncompute/src/lib.rs`: provenance and release planning.
- `crates/gala-gir/src/lib.rs`: GIR data model and lowering.
- `crates/gala-cli/src/main.rs`: current command surface.

The canonical repository is [gala-pl/gala](https://github.com/gala-pl/gala).
