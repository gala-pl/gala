---
title: Cookbook
description: Small Gala patterns organized by the kind of program they exercise.
---

The cookbook uses short examples to make the language rules concrete. Examples that require a
simulator or runtime are labeled as design examples while those components are still under
construction.

- [Classical](/docs/cookbook/classical): functions, expressions, and data flow.
- [Quantum](/docs/cookbook/quantum): resource ownership, gates, measurement, and uncomputation.
- [Hybrid](/docs/cookbook/hybrid): how a future differentiable workflow fits together.
