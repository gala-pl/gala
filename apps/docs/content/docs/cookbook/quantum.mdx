---
title: Quantum patterns
description: Explicitly thread qubits and keep the measurement boundary visible.
---

## Thread a gate result

```gala
fn hadamard(q: Qubit) -> Qubit quantum {
    return h(q);
}
```

The input binding is consumed by `h`; the returned binding is the live resource. This style is
more verbose than in-place sugar but makes linear ownership obvious.

## Return all resources from a two-qubit operation

```gala
fn pair(a: Qubit, b: Qubit) -> (Qubit, Qubit) quantum {
    return cx(a, b);
}
```

## Cross into probability

```gala
fn read(q: Qubit) -> Measured<Bool> prob {
    return measure(q);
}
```

The `prob` annotation communicates that the function is not a reversible unitary kernel. The
current simulator and runtime do not yet execute this program, but the frontend and diagnostics
model are built around this distinction.
